# OneDrive-Desktop-githubwithshubham

A beginner-friendly repository for learning how to use GitHub.

## How You Can Do It

### 1. Clone the Repository

```bash
git clone https://github.com/Gauravdada/OneDrive-Desktop-githubwithshubham.git
cd OneDrive-Desktop-githubwithshubham
```

### 2. Run the Python Script

Make sure you have Python installed, then run:

```bash
python hi.py
```

### 3. Make Changes

1. Edit any file (e.g., `hi.py`) with your changes.
2. Stage your changes:
   ```bash
   git add .
   ```
3. Commit your changes:
   ```bash
   git commit -m "your commit message"
   ```
4. Push to GitHub:
   ```bash
   git push origin main
   ```

### 4. Create a New Branch

```bash
git checkout -b my-new-branch
```

### 5. Open a Pull Request

After pushing your branch, go to the repository on GitHub and click **"Compare & pull request"** to open a PR.
